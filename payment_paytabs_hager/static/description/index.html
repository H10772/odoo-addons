Installation Guide

Setup in Minutes

No coding required. Accept payments almost instantly.

1

Install Module

Find "PayTabs Payment Provider" in Odoo Apps and click Install.

2

Get Credentials

Log into PayTabs dashboard to get your Profile ID and Server Key.

3

Configure Odoo

Go to Invoicing → Configuration → Payment Providers and select PayTabs Egypt.

4

Go Live!

Enter credentials, switch to Enabled, and start accepting payments.
