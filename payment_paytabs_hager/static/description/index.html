Installation

Setup in Minutes

No coding required. Be ready to accept payments almost instantly.

1

Install Module

Find "PayTabs Payment Provider" in Odoo Apps and click the Install button to begin.

2

Get Credentials

Log into your PayTabs merchant dashboard to retrieve your Profile ID and Server Key.

3

Configure Odoo

Navigate to Invoicing → Configuration → Payment Providers and select PayTabs Egypt.

4

Go Live

Enter your credentials, switch the state to Enabled, and start accepting live payments.
