Quick Setup Guide

  1. Install the Module Search for "PayTabs Payment Provider" in Odoo Apps and click Install
  2. Get PayTabs Credentials Log in to your PayTabs merchant dashboard and get your Profile ID and Server Key
  3. Configure Provider Go to Invoicing → Configuration → Payment Providers → PayTabs Egypt
  4. Enter Credentials Fill in your Profile ID and Server Key, then enable the provider
  5. Test Payment Create a test order and complete a payment to verify the integration

Requirements

  • Odoo 17.0 or higher
  • Active PayTabs Egypt merchant account
  • Valid PayTabs Profile ID and Server Key
  • SSL certificate (HTTPS) for production use

Configuration Details

After installation, configure the following in the payment provider settings:

  • Profile ID: Your PayTabs merchant profile ID (numeric)
  • Server Key: Your PayTabs API server key
  • Multi-Currency: Enable only if your account supports it
  • State: Set to "Enabled" to activate payments
  • Payment Journal: Select the accounting journal
🔒 Security Reminder Keep your Server Key confidential. Never share it publicly or commit it to version control.
