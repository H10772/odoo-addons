PayTabs Payment Provider for Odoo 17

Secure Payment Integration for Egypt & Middle East

Why Choose PayTabs?

Integrate PayTabs payment gateway seamlessly with your Odoo 17 instance. Accept credit and debit card payments from customers across Egypt and the Middle East with a secure, PCI-compliant payment solution.

🔐 Secure Payments

PCI-DSS compliant payment processing with PayTabs Egypt secure gateway. Your customers' data is always protected with industry-standard encryption.

💰 Multi-Currency Support

Support for Egyptian Pound (EGP) by default, with optional multi-currency support for USD, EUR, GBP, and SAR.

↩️ Refund Support

Process full or partial refunds directly from Odoo with just a few clicks. Refunds are processed instantly through PayTabs API.

⚡ Real-time Updates

Instant transaction status updates via server-to-server callbacks. Know immediately when payments are completed or failed.

🔄 Redirect Flow

Secure redirect-based payment flow that keeps your customers safe. Customers are redirected to PayTabs secure payment page.

📱 Mobile Ready

Fully responsive payment experience on all devices and screen sizes. Works perfectly on desktop, tablet, and mobile.

Supported Currencies

🇪🇬 EGP - Egyptian Pound 🇺🇸 USD - US Dollar 🇪🇺 EUR - Euro 🇬🇧 GBP - British Pound 🇸🇦 SAR - Saudi Riyal
💡 Important Note: EGP is supported by default on all PayTabs Egypt accounts. Multi-currency support (USD, EUR, GBP, SAR) requires special activation from PayTabs. Contact PayTabs support to enable multi-currency.

Quick Setup Guide

Step 1: Install the Module

Search for "PayTabs Payment Provider" in Odoo Apps and click Install

Step 2: Get PayTabs Credentials

Log in to your PayTabs merchant dashboard and get your Profile ID and Server Key

Step 3: Configure Provider

Go to Invoicing → Configuration → Payment Providers → PayTabs Egypt

Step 4: Enter Credentials

Fill in your Profile ID and Server Key, then enable the provider

Step 5: Test Payment

Create a test order and complete a payment to verify the integration

Requirements

  • ✓ Odoo 17.0 or higher
  • ✓ Active PayTabs Egypt merchant account
  • ✓ Valid PayTabs Profile ID and Server Key
  • ✓ SSL certificate (HTTPS) for production use

Configuration Details

After installation, configure the following in the payment provider settings:

  • Profile ID: Your PayTabs merchant profile ID (numeric)
  • Server Key: Your PayTabs API server key
  • Multi-Currency: Enable only if your account supports it
  • State: Set to "Enabled" to activate payments
  • Payment Journal: Select the accounting journal
🔒 Security Reminder: Keep your Server Key confidential. Never share it publicly or commit it to version control.
